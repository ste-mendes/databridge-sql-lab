# 🚀 DataBridge SQL Lab

### Da formação à carreira em Dados

Bem-vindo ao **DataBridge SQL Lab**, o laboratório de aprendizagem SQL do **DataBridge**, um programa de mentoria voltado ao desenvolvimento de competências técnicas e profissionais para quem deseja ingressar no mercado de Dados.

Este repositório reúne materiais de estudo, exemplos comentados, exercícios práticos e desafios que simulam situações encontradas no dia a dia de um Assistente de Dados ou Analista de Dados Júnior.

---

## 🎯 Objetivo

Desenvolver habilidades em SQL por meio de uma aprendizagem progressiva, conectando conceitos técnicos à resolução de problemas reais de negócio.

Ao longo dos exercícios, você aprenderá a:

- Consultar, filtrar e organizar informações em bancos relacionais.
- Relacionar tabelas e consolidar dados.
- Construir indicadores e análises de negócio.
- Identificar inconsistências e tratar valores ausentes.
- Criar views, funções e procedimentos armazenados.
- Aplicar SQL na resolução de desafios profissionais.

## 👥 Para quem é este repositório?

- Estudantes e recém-formados que desejam ingressar na área de Dados.
- Profissionais de Administração e áreas correlatas em transição de carreira.
- Iniciantes em SQL que buscam exercícios práticos.
- Participantes da mentoria DataBridge.

**Pré-requisitos:** conhecimentos básicos de informática, raciocínio lógico e disposição para aprender. Não é necessário possuir experiência prévia com bancos de dados.

## 🛠️ Tecnologias utilizadas

- Microsoft SQL Server — banco de dados relacional.
- SQL Server Management Studio (SSMS) — execução e gerenciamento de consultas.
- T-SQL — linguagem SQL utilizada no SQL Server.
- Google Colab — ambiente dos notebooks educacionais.
- GitHub — versionamento e compartilhamento dos materiais.

> Os exemplos foram desenvolvidos inicialmente para SQL Server. Algumas consultas podem exigir adaptações para outros bancos de dados.

## 📚 Trilha de aprendizagem

| Módulo | Conteúdo | Nível |
|---|---|---|
| 01 | Fundamentos de SQL: SELECT, WHERE, ORDER BY | Iniciante |
| 02 | JOINs, agregações, GROUP BY e subconsultas | Básico/intermediário |
| 03 | CASE, COALESCE e funções de janela | Intermediário |
| 04 | Views, Functions e Stored Procedures | Intermediário |
| 05 | Triggers, transações e ROLLBACK | Intermediário/avançado |
| 06 | Desafios integradores e análise de negócios | Prático |

## 📂 Organização do repositório

- `01-fundamentos/`: primeiros conceitos e consultas SQL.
- `02-consultas-intermediarias/`: relacionamentos e análises.
- `03-sql-avancado/`: recursos de programação T-SQL.
- `04-desafios/`: problemas e projetos práticos.
- `datasets/`: orientações para obtenção e preparação das bases.
- `notebooks/`: notebooks de aprendizagem.
- `solucoes/`: resoluções comentadas dos exercícios.

## 💻 Como começar

1. Instale o SQL Server e o SQL Server Management Studio, ou utilize um ambiente SQL Server já disponível.
2. Clone o repositório ou faça o download dos arquivos.
3. Consulte as instruções da pasta `datasets/` para preparar a base de dados.
4. Comece pelos exercícios de `01-fundamentos/`.
5. Execute as consultas e registre suas observações.
6. Compare suas soluções com os gabaritos quando disponibilizados.

```bash
git clone https://github.com/SEU-USUARIO/databridge-sql-lab.git
cd databridge-sql-lab
```

Substitua `SEU-USUARIO` pelo usuário ou organização responsável pelo repositório.

## 🧩 Metodologia dos exercícios

Os desafios são organizados em quatro etapas:

**1. Contexto de negócio:** apresentação de um problema que poderia ocorrer em uma empresa.

**2. Objetivo técnico:** identificação das operações SQL necessárias.

**3. Desenvolvimento:** construção e execução das consultas.

**4. Análise dos resultados:** interpretação dos dados e elaboração de conclusões.

A proposta não é apenas escrever consultas que funcionem, mas compreender como os resultados podem apoiar decisões.

## 📊 Projetos práticos

Os projetos poderão abordar diferentes contextos empresariais:

- Análise de catálogo audiovisual.
- Indicadores comerciais e financeiros.
- Análise de clientes e produtos.
- Qualidade e tratamento de dados.
- Desenvolvimento de views para relatórios gerenciais.

Novos exercícios e projetos serão adicionados conforme a evolução dos materiais.

## 🤖 Inteligência Artificial como apoio

Ferramentas de IA podem ser utilizadas para estudar conceitos, compreender mensagens de erro e revisar consultas.

Entretanto, todo código sugerido deve ser compreendido, testado e validado.

**A IA é uma ferramenta de apoio ao aprendizado, não um substituto para o raciocínio analítico.**

## 🏆 Desafios e portfólio

Recomendamos que os estudantes documentem seus projetos com:

- Descrição do problema de negócio.
- Estrutura das tabelas utilizadas.
- Consultas SQL desenvolvidas.
- Resultados e interpretações.
- Principais dificuldades e aprendizados.

Esse processo contribui para a construção de um portfólio profissional.
